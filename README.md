# Конструктор значков

Браузерное приложение для подготовки круглых значков к печати на А4.

Опубликованная версия: https://natadau.github.io/badge-constructor/ (ветка `main`). Новые возможности и проверки безопасности готовятся в отдельных ветках и не попадают в опубликованное приложение без согласования.

Все изображения обрабатываются локально в браузере. Сохранённый проект содержит сами изображения и настройки в одном JSON-файле. Перед открытием файла проекта приложение проверяет формат и ограничения ресурсов. Защита от необычных или повреждённых файлов не может полностью исключить сбои браузера, особенно на устройствах с небольшим объёмом памяти.

Проверенные диаметры бумажных заготовок: 33 мм (пластик), 35 мм (металл 25 мм), 48,5 мм (металл 37 мм), 54 мм (металл 44 мм).

Проект независим от [конструктора АДК](https://github.com/NATADAU/adk-constructor).
